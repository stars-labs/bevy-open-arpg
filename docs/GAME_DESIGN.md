# 暗影圣匣 · 总策划

本文件是全游戏策划的入口：定位、核心循环、系统总览、缺口与路线。各系统的详细设计放在同目录的专题文档里。

## 定位

原创暗黑奇幻俯视角 ARPG。一局 20–40 分钟的章节推进，两章战役循环 + 无边荒野 + 裂隙/试炼等终局玩法。
右键移动、左键攻击、Q/E/R 三个主动技能、Shift 闪避、Y 蓄能爆发。默认中文。

三条体验支柱：

1. **出手有重量**：伤害在动作接触帧结算；近战卡刀拖刀，远程以命中后坐、接触碎屑和音效表达。
2. **选择改变下一次出手**：职业、技能、符文、天赋、装备的每个选择都必须在下一场战斗里看得见。
3. **每升一级都有新东西**：1–6 级每级解锁一个技能，之后巅峰等级持续给天赋点。

## 核心循环

```
选职业 → 进章节 → 清怪/精英/事件 → 升级解锁技能 + 掉落装备 → 配技能与符文、点天赋
      → 章节首领 → 下一章 / 更高难度 → 裂隙、试炼、悬赏等终局循环
```

## 已知缺口与后续路线（不在本轮范围）

- 手柄没有技能键位绑定。
- 存档只有单槽，没有多角色列表；换职业需要开新局。
- 武器外观不随掉落变化（每职业固定一把武器模型）。
- 没有技能等级/技能点（成长由天赋与符文承担）；若后续要做，放在技能书每个技能下。
- 没有职业专属装备词缀与职业套装。
- 音效仍需人工试听验收。

## 设计约束

- 数值进 `assets/data/*.ron`，不写死在代码里。
- 模型由 Blender 生成器产出，音效由音频生成器产出，不手改二进制。
- 原创设计，不复刻任何商业游戏的专有素材、名称或图标。
- 界面语言单一：中文界面不出现英文残留。
