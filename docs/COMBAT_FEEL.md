# 战斗手感：响应、节奏、反馈与容错

状态：2026-11-05 本轮实现与验收完成。目标是在真实攻击循环中建立清晰因果，不靠堆特效掩盖输入迟滞。右键移动、左键攻击，Q/E/R与Shift保留原输入职责。本文取代旧的全局卡刀方案。

## 验收要求

| 项目 | 当前实现 | 必须检查的行为 |
|---|---|---|
| 输入响应 | 普攻/技能/闪避短输入缓存，显式技能优先；收招窗口允许衔接和移动 | 早按不轻易吞输入，过期不自动施放，UI/暂停不泄漏指令 |
| 攻击节奏 | 普攻更早接触、紧凑起手与快速挥刃；重击更长蓄势与更强接触；出手期间朝向保持、允许平移，收招可转向，闪避可打断 | 起手、挥击、接触、收招可辨；刀刃领先，脚底稳定，确认命中不倒放 |
| 局部卡刀 | 仅接触双方动作短暂停顿，保持—拖刀—释放；分段积分适配长帧 | 世界计时、其它敌人和投射物不减速；召唤物命中不暂停主人 |
| 命中因果 | 成功接触才有受击、接触音和震动；挥空仅轻剑风及原动作 | 空挥和空技能不伪造命中；暴击、重击、击杀、破防有不同强度 |
| 视觉克制 | 每目标一层主要接触效果，已有击退/挤压；远程维持施法与元素语言 | 多目标不叠震屏，不全屏闪白，不让技能光效遮住目标轮廓 |
| 听觉层次 | 剑风/接触分离，金属/骨质/肉体区别，确定性轻微变调和音量变化 | 技能伤害不重复播放通用命中音；同帧最多一条主要语义提示和一层接触 |
| 闪避与中断 | 站立也按当前意图闪步，方向稳定，短无敌与冷却，按帧内有效时长积分 | 不穿封闭边界，闪避取消未释放伤害；已经飞出的箭不凭空消失 |
| 状态清理 | 菜单/暂停清缓存，读档清未释放攻击、在途效果与局部停顿 | 不在恢复菜单后误出招，不把旧镜头偏移、追击或标记留在新状态 |

参数集中在 `assets/data/combat_feel.ron`。普通命中基础停顿35ms，暴击55ms，重击约70ms，破防85ms；根据冲击与敌人等级有限调整。普攻接触约在周期36%，恢复取消60%，续击68%；角色移动/转向、技能冷却与世界时间不随局部暂停缩放。

八种表现手段按作用选择：停顿用于接触、震屏用于真实冲击、碎屑用于材质、挤压用于受击、短轨迹用于运动方向、音高变化减少机械重复。这里不添加常驻满屏闪白或全局慢镜；召唤物数量多时尤其不能拖慢玩家控制。

## 实现边界

- `src/combat/feel.rs`：配置及输入/范围/清理契约。
- `src/combat.rs`：真实接触、输入优先级、伤害与声音触发；开发录制的必暴击仅在显式dev fixture内覆盖，正式暴击上限不变。
- `src/player.rs`：分阶段姿态、局部动画时钟、恢复衔接、定向闪步。
- `src/feedback.rs`：局部暂停精确积分、相机偏移恢复、音频分类与限流。
- `src/combat/presentation.rs`：接触素材和目标材质，暴击/击杀强度。
- `src/enemy.rs`、`src/combat/summons.rs`：受击者和召唤物自己的动作时钟。
- `src/save.rs`：读档后清除瞬时战斗状态。
