# 战斗成长与命中表现

## 策划：让投入改变下一次出手

目标是同装备、同敌人下，第一点天赋就能改变战斗结果，持续投入仍有收益。
当前缺口：六级后不再获得天赋点，八阶不可达；专注中间等级冷却重复；攻击周期缩短而动作仍固定；命中特效没有保留符文身份。

| 路线 | 玩法结果 | 美术与动作 | 验收 |
| --- | --- | --- | --- |
| 愤怒 | 保留伤害成长，增强真实命中冲击与后坐，首领限制位移 | 接触碎钢更有方向与重量，短卡刀；剑长不变 | 对比 0/1/4/8 阶敌人位移和命中停顿 |
| 活力 | R/Q/E 命中获得护盾，每次施法一次；保留生命与药水成长 | 玩家短金色护佑刻痕，护盾值真实增加 | 空挥无护盾，多目标不倍增，下次受伤先扣护盾 |
| 专注 | 普攻有效命中额外获得怒气，每次挥刀一次；冷却逐阶下降 | 动作、命中时刻、攻击周期同步加快，短青色回流 | 零怒气：0 点一刀 18，1 点一刀 20，可接裂地斩 |

巅峰等级继续给予天赋点，升级卡展示真实奖励；不重置现有进度。
数值由 `assets/data/player.ron` 维护，保留原有四阶、八阶精通。

## 战斗设计：起手 → 接触 → 卡刀 → 拖刀 → 收刀

普通挥刀和裂地斩的伤害在动作接触帧结算。只有有效接触才产生命中停顿和接触效果。
停顿使用真实时间，先短暂停住，再带阻力释放并恢复；普通、重击、破甲分层，多目标不累加时长。
专注加快整个攻击周期，伤害延迟随周期同比缩短，避免新动作截断上一刀。空挥不触发卡刀。

## 美术：锻铁、碎骨、余烬刻痕

颜色辅助识别，形状与运动表达实际机制。每个目标每次接触只保留一层主要命中效果。

| 符文 | 命中语言 |
| --- | --- |
| 破绽 | 向外裂开的细金裂纹与干脆金属声 |
| 血伤 | 沿刀势甩出的低亮红滴与短撕裂声 |
| 净化 | 白金断环收束，短清脆冲击 |
| 收割 | 暗红细流回到角色，低沉吸附声 |
| 余烬 | 少量焦红火屑外散，短爆燃声 |
| 寒霜 | 敌人脚边六向冰裂，碎冰声 |

不使用巨大光球、柱体、满屏刀光；普通攻击保持剑刃和敌人轮廓清晰。

## 技术美术与验收

接触由实际伤害结算发送类型化消息，携带符文、强度、来源和目标，不从日志字符串猜测。
模型由 Blender 生成器导出，声音由音效生成器导出；WebGPU 使用不透明材质，运动和收束完成消退。
范围命中音效每帧选最强一声并限流，防止多目标音量叠加。

固定装备、无暴击的隔离场景对比天赋 0/1/4/8 阶与六种符文，记录伤害、怒气、护盾、接触帧、停顿窗口及敌人位移；以连续帧验收，不用单张摆拍代替动作验证。
